# Hux direction

**V1-PROOF comes first:** a small, affordable robot that really balances, drives and moves its legs a little. Spend strictly less than $1,000, reuse useful equipment and finish an observable demonstration.

The long-term stair robot remains an idea in the [parked archive](archive/stair-v1/README.md). It does not dictate this chassis, its motors, battery, software or purchase sequence. There is no requirement that the proof frame later climb stairs.

Carry forward what the proof teaches: real controller timing, wheel response, mechanical play, measured mass/CoM, safe fault handling and a disciplined build log. [V1-PROOF](v1-proof.md) defines the current result.
