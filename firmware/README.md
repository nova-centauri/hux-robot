# Firmware

No embedded implementation yet. **2026-10-03:** one Pico 2 with pre-soldered headers is received, untested. Begin the [USB/LED bring-up checklist](../docs/checklists/2026-10-03-pico-bringup.md) using official vendor examples. V1-PROOF targets C/C++ with `PICO_BOARD=pico2`, the received SparkFun LSM6DSO over SPI (sensor qualification pending), two encoder wheel drivers and later two small leg servos. The LSM6DSO replaces the earlier LSM6DSOX selection; use its own register initialization. [Software contract](../docs/software.md) and [software checklist](../docs/checklists/software-bringup.md).

Robot modes are `DISARMED`, `BALANCE`, `DRIVE`, `FAULT`. A proposed `BENCH_ARMED` state supports a rigidly fixed single leg and lifted wheel before balance; see the [bench controls and test plan](../docs/one-leg-bench.md). No bench controller has been implemented. CAN, one-wheel stance modes and stair control belong to the parked project. First jobs can be readback, bounded actuator motion and fault checks in the fixture, followed by sensor logging and pinned-leg balance.
