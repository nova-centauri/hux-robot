# CAD

Empty on purpose. Drop printable / CAD sources here when they exist.

**Gate:** several **2D sketch layouts** (side / front / top + linkage) must exist **before** Blender or other 3D CAD (R23). A `.blend` with no preceding 2D is a process miss.

V1 expected: one wheel-leg — **carbon-tube spars** + printed / machined **end fittings**, sized toward a ~9.5" step inside **~24" tall / ~10" wide** (see [`../docs/mechanical.md`](../docs/mechanical.md) and [`../docs/checklists/mechanical-v1.md`](../docs/checklists/mechanical-v1.md)).

2D scans / exports can live here too. Keep intentional exports (`.stl`, `.3mf`, `.step`). Scratch backups are gitignored.
